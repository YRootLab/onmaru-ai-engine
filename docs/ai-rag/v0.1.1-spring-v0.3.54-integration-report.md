## 2. 변경 내용 요약 (AI Engine v0.1.1)

1. **CallbackProgressSink 계약 정합화 (`src/onmaru_ai/progress/`)**:
   - Spring 엔드포인트 `/internal/v1/ai/runs/{runId}/progress`로 경로 고정.
   - `X-Run-Progress-Token` 및 `Authorization: Bearer` 헤더 전송.
   - 기본 `schemaVersion`을 `"internal.ai.progress.v1"`로 변경.
2. **Spring Place Lookup Adapter MCP Tool 연동 (`src/onmaru_ai/adapters/spring_place.py`)**:
   - URL을 `/internal/mcp/journey/tools/journey_execute_approved_lookup`로 변경.
   - 요청 시 Spring이 요구하는 `queryGrantId`, `regionCode`, `category`, `limit` (최대 5건) 준수.
   - Spring 응답의 `catalogVersion`과 장소 필드(`placeId`, `name`, `category`, `address`, `regionCode`, `latitude`, `longitude`) 완전 파싱.
3. **Orchestration Engine 파이프라인 실제 연결 (`src/onmaru_ai/orchestration/engine.py`)**:
   - `execute_run` 시 실제 `progress_sink`가 주입되면 각 진입 단계(`PREPARING_INPUT` -> `RETRIEVING` -> `SELECTING_EVIDENCE` -> `GENERATING` -> `CHECKING_OUTPUT`) 순차 발행.
   - `SQL_ONLY` 및 `SQL_PLUS_RETRIEVAL` 경로에서 Spring MCP place lookup adapter 실제 호출.
4. **Production Readiness 검증 강화 (`src/onmaru_ai/main.py`)**:
   - `/ready` 호출 시 `internal-ai.service-token` 등 필수 시크릿 주입 상태를 검증하여 미설정 시 503 반환.
