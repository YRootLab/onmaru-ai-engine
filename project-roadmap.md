# Project roadmap

## Direction

- Evolve the FastAPI baseline toward the AI-RAG design in [docs/ai-rag/README.md](docs/ai-rag/README.md).
- Keep the AI engine image publication separate from the backend-owned Lightsail deployment, as described in [README.md](README.md).

## Milestones

- Establish independent validation and image publication for the AI engine.
- Deliver corpus indexing, retrieval, and evidence-based generation in stages.
- Validate coexistence with the backend before operating the AI engine in production.

Track scoped implementation work in GitHub Issues after triage.
